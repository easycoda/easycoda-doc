# 快速入门

本指南将引导您设置 EasyCoda 并创建第一个 AI 应用。完成后，您将拥有一个功能完备的 AI 应用。

## 准备工作

开始之前，请确保已满足以下条件：

- **账号** 您已经拥有一个 EasyCoda 注册账号
- **积分** 您的账号有可用积分，我们为每一个新注册账号赠送 500 积分，该积分足够使您构建一个大型项目。详情查阅 [积分使用指南](/zh/guides/credits)。

## 创建项目

当您登录您的账号之后，会跳转至 [EasyCoda 控制台](https://easycoda.cn/console/new) 页面，您也可以在浏览器里打开该页面，默认会进入新建项目页面，在该页面，您只需要用自然语言描述您的想法和需求，点击发送按钮即可创建一个新的项目。

![EasyCoda Quick Start](/zh-quickstart.webp)

例如：

> 写一个科技企业官方网站

> 写一个博客网站

当您提交了您的需求描述之后，团队领导者智能体会和您稍后详细讨论需求明细和技术选型，您的需求描述越详细完成度越高。

### 默认项目参数

默认情况下，您创建的项目具有以下属性， 您可以在提交您的需求之前修改以下任何参数：
- 公开项目：公开项目意味着登录平台的所有用户都可以看到该项目并且可以克隆您的项目，基于您的项目进行二次开发。您的会话历史记录不会被克隆，只有您可见。
  您也可以设置为私有项目，对于私有项目，默认只有您自己可以访问。您也可以邀请指定用户访问您的私有项目，更多详情参考 [项目管理](/zh/guides/projects)。

- 智能体团队：默认使用 React 网页应用的智能体团队。该智能体团队主要实现基于 React 的网页前端应用，如果您需要全栈应用，如带数据库的应用，请选择全栈智能体团队。在输入框下方下拉菜单里选择您的智能体团队，项目智能体团队一旦选择之后，后续不可更改。可用智能体团队参考 [智能体团队指南](/zh/guides/agent-teams)。

- 工作空间：您可以选择您指定的工作空间，如果未指定，项目将创建在您的账户的默认生成工作空间里。更多工作空间参考 [工作空间指南](/zh/guides/workspaces).

- 模型选择：默认模型为 `DeepSeek-V4-Flash` 模型，会员用户可以选择 `DeepSeek-V4-Pro` 模型，模型一旦选择，后续不可更改。


## 启动沙盒环境

当您提交了您的项目开发需求之后，会自动导航至项目聊天页面，在该页面初始化完成之前，系统会为项目创建云端的沙盒环境，沙盒环境根据您选择的智能体团队类型动态创建，在系统负载正常的情况下，沙盒环境的启动就绪时间大概在 15-20s 左右，如果系统资源紧张或者繁忙，等待时间可能更长，请您耐心等待环境启动完成。更多详情参考 [开发环境指南](/zh/guides/dev-sandbox)


## 开始聊天

当项目开发环境准备就绪之后，项目聊天页面会分为两列，左侧会展示您和当前智能体团队领导者的聊天内容，右侧会展示当前项目的预览页面。您可以在左侧和智能体团队领导者继续通过自然语言聊天的方式确定开发任务，提出 Bug， 或者提出重构修改等请求。随着开发任务的推进，右侧的预览页面会自动重载展示当前项目已经实现的功能。

注意：

- 聊天页面为可重入设计，您可以刷新，关闭，或者重新打开该页面，不会影响智能体团队的任务执行。
- 您只能和智能体团队领导者对话，不能和团队成员直接对话。您可以直接让团队领导者直接将任务委派给某个特定智能体。
- 智能体团队领导者显示头像为 `TL`。
- 智能体团队成员的输出为可折叠面板，头像为成员名称的首字母缩写。如前端智能体（Frontend Agent）缩写为 `FA`。
- 如果出现多个团队成员的输出面板，则表示团队领导者将多个任务并行发送给多个智能体成员。
