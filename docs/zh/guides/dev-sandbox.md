# 沙盒环境

EasyCoda 为每个智能体团队提供云端的沙盒环境。智能体团队成员可以在该沙盒环境里执行命令，调试程序等。


## 环境初始化

当您新建一个项目，提交了需求之后，系统会自动创建沙盒环境，该沙盒环境主要基于 Linux 的虚拟机，并且提供了访问该沙盒网页终端。您可以在项目的聊天页面，点击终端按钮来打开沙盒的访问。

当系统资源充足时，沙盒的启动就绪时间大概为 15-20s 左右，资源繁忙时，启动时间可能稍长。

## 沙盒生命周期

当您的智能体任务开发完成，并且 30 分钟内没有访问沙盒环境时，系统会自动关闭沙盒环境。您的资源不会被删除，只是关闭了虚拟机，回收计算资源给其他用户使用。当您下次打开项目聊天时，会为您自动启动沙盒环境。您的环境中的代码资源等均会恢复。

当您的沙盒环境被关闭之后，您的项目的预览地址会访问失败。

## 沙盒资源配置

默认前端项目的沙盒配置 2vCPU， 2GB 内存， 10GB 磁盘。 后端项目和全栈项目沙盒配置为 2vCPU，4GB内存，10GB磁盘。
