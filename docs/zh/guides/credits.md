# 积分使用指南

本指南将详细介绍 EasyCoda 的积分是如何工作的， 帮助您更好的了解掌握项目积分使用情况。EasyCoda 采用简单，透明，高效的积分设计。

## 积分概述

EasyCoda 主要使用积分（Credits）来抵消模型的词元（Token）消耗。简单来说，积分数 * 10000 = 总词元数（total tokens）。您的初始账户赠送的 500 积分 = 500 * 10000 = 5000000 总词元。


## 积分扣除规则

积分主要在您和 AI 智能体聊天时才会扣除，其他服务不影响积分扣除，并且我们只针对输出的词元（token）做积分扣除。您的输入词元和智能体团队的输入词元，例如文件读取，在缓存命中的情况下，不会参与积分扣除。

简而言之，我们只针对模型的输出词元和缓存未命中的词元收取费用，得益于 EasyCoda 高效的缓存命中设计，这极大的降低了开发成本。您默认初始账户赠送的 500 积分完全可以帮您构建几个大型项目。

当您的项目任务取消时，我们只针对已经完成的任务采取积分扣除。例如当您某轮会话正在进行中，您点击取消任务时，该轮会话产生的词元（token）消耗不会参与积分扣除。

EasyCoda 支持会话总结，并且会话总结产生的词元（token）消耗不计入积分使用。

项目的积分使用情况可以在项目的详情页面查看。在项目列表页面点击更多操作按钮，在下拉菜单里选择设置，即可进入项目详情页面。

您的账户总积分使用概览可以在控制台的左下角，点击账户头像按钮，在弹出的菜单里选择 `使用情况` 进入资源使用面板。


## 积分购买

您可以通过以下两种方式购买积分，您可以在 [价格页面](https://easycoda.cn/pricing) 购买积分。

1， 升级您的账户。当您订阅标准套餐或者高级套餐时，套餐会包含一定的积分数量和其他的一些权益。套餐包含的积分会在每月账单扣除成功后赠送至您的账户。套餐赠送的积分未使用完时月底会清零，不会流转。

2， 单独购买积分。 您也可以在价格页面单独购买指定数量的积分，单独购买的积分永久有效，未使用时不会清零。

积分不可兑现，转让。
